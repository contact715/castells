# Академия для подрядчиков — черновая структура программы

Черновик по задаче из docs/SEO_DAILY.md («Академия: черновая структура программы»).
**Не публиковать.** Это предложение на утверждение владельцу, не готовый продукт.
Ничего из этого не строится и не появляется на сайте, пока владелец не ответит
на три открытых вопроса в разделе «Академия для подрядчиков» файла SEO_DAILY.md
(где живёт academy.castells.com, кто пишет уроки, в каком формате).

Источник: бриф владельца от 24 августа (см. SEO_DAILY.md) и перечень разделов
из пропозала для клиента General Contractor (Sacramento), который владелец
прислал в тот же день. Сам документ пропозала в репозитории не лежит — ниже
только те его разделы, что уже пересказаны в SEO_DAILY.md. Специфику под
restoration/GC оттуда не переношу, только структуру разделов.

---

## Как собрана эта структура

Бриф владельца дал список тем без порядка. Пропозал для клиента дал готовый
каркас, для одной ниши и одного клиента, но по разделам он почти совпадает с
темами брифа — значит, это рабочий скелет и для общей программы. Ниже —
попытка совместить оба списка в последовательность, в которой предприниматель
реально проходит эти шаги: сначала регистрирует бизнес, потом решает, как он
выглядит, потом — где его находят, потом — как из этого приходят деньги.

## Модуль 1. Запуск бизнеса
Тема из брифа владельца: «как запускать бизнес — регистрация, структура,
первые шаги».
- регистрация бизнеса в США: выбор формы (тема из брифа, требует раскрытия —
  структуры и юрисдикции конкретно не названы)
- первые шаги после регистрации

## Модуль 2. Фирменный стиль
Тема из брифа: «фирменный стиль / айдентика». В пропозале GC Sacramento это
отдельный первый раздел — то есть у нас уже есть опыт, с которого можно
писать урок, а не пересказывать чужое.
- зачем подрядчику фирменный стиль до того, как есть сайт
- из чего он состоит на практике (то, что мы обычно делаем клиенту)

## Модуль 3. Сайт
Тема из брифа: «основы сайтов». В пропозале GC Sacramento сайт разложен на три
формата — визитка, лендинг, корпоративный сайт с SEO. Это готовое деление,
можно взять как есть.
- три формата сайта и чем они отличаются по задаче, а не по цене (цену не
  берём — она из пропозала одного клиента, не источник для программы)
- что нужно, чтобы сайт вообще нашли (стык с модулем 5)

## Модуль 4. Основы маркетинга
Тема из брифа: «основы маркетинга» — самая широкая, требует уточнения у
владельца, что именно сюда входит помимо перечисленного в модулях 5-6.

## Модуль 5. Как вас находят
Тема из брифа: «генерация лидов». Пропозал GC Sacramento даёт для этого готовые
подтемы:
- Google Business Profile и local SEO
- платный трафик по каналам
- контент-производство (фото и видео на объектах)
- SEO и контент

## Модуль 6. Продажи
Тема из брифа: «продажные технологии и техники продаж». Пропозал добавляет
сюда практическую часть — CRM и автоматизация продаж (кто-то должен вести
заявку от звонка до счёта, это не только техника разговора).
- CRM и автоматизация продаж
- сами техники продаж (тема из брифа, содержание не раскрыто — нужен вклад
  владельца, у нас в репозитории нет учебного материала на эту тему)

## Модуль 7. Базовые основы — требует уточнения
Формулировка из брифа: «базовые основы (какие именно — уточнить у владельца:
бухгалтерия, юридическая часть, что-то ещё)». Без ответа владельца этот модуль
нельзя раскрыть даже черновиком — не выдумываю содержание.
